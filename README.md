# تمرین و یادگیری JavaScript

این مخزن شامل مجموعه‌ ای از تمرین‌ ها و مثال‌ های کاربردی برای یادگیری زبان برنامه‌نویسی JavaScript است. مطالب این Repository به‌ صورت مرحله‌ به‌ مرحله ، از مفاهیم پایه شروع شده و تا مباحث پیشرفته و برنامه‌نویسی OOP ادامه پیدا می‌ کنند. هدف از این مجموعه، یادگیری عمیق‌ تر JavaScript، تقویت مهارت حل مسئله و تمرین مفاهیم برنامه‌نویسی از طریق نوشتن کد است.

## 📚 Topics

| File | Topic |
|---|---|
| `01-basics-and-variables.js` | Variables, Data Types, and Type Conversion |
| `02-operators-and-conditionals.js` | Operators, Comparisons, and Conditional Statements |
| `03-loops.js` | Loops, Break, and Continue |
| `04-functions.js` | Functions, Scope, Hoisting, and Closures |
| `05-arrays.js` | Arrays and Their Useful Methods |
| `06-objects.js` | Objects, Properties, and Destructuring |
| `07-data-structures.js` | JSON, Map, and Set |
| `08-error-handling-and-modules.js` | Error Handling and Modules |
| `09-asynchronous-javascript.js` | Promises, Async/Await, and the Fetch API |
| `10-object-oriented-programming.js` | Classes, Constructors, Inheritance, and Encapsulation |

## 🎯 Learnin Target

- آشنایی با مفاهیم پایه و ساختار زبان JavaScript
- تسلط بیشتر بر متغیرها، انواع داده و عملگرها
- درک نحوه کار توابع، Scope و Closure
- کار با Array و Object و متدهای آن‌ها
- آشنایی با مدیریت خطا و ساختار Modules
- درک مفاهیم Asynchronous Programming
- یادگیری برنامه‌ نویسی شی‌ گرا (OOP)
- تقویت مهارت حل مسئله و نوشتن کد خوانا

## 🚀 Run Codes

برای اجرای تمرین‌ ها به موارد زیر نیاز دارید:

- نصب [Node.js](https://nodejs.org/)
- یک ویرایشگر کد مانند [Visual Studio Code](https://code.visualstudio.com/)

پس از دریافت پروژه، ترمینال را در پوشه آن باز کنید و فایل موردنظر را با دستور زیر اجرا کنید:

```bash
node 01-basics-and-variables.js
```

برای اجرای سایر تمرین‌ ها، نام فایل را تغییر دهید.

## 📝 Suggested Study Method

برای یادگیری بهتر، پیشنهاد می‌ شود تمرین‌ ها را به ترتیب زیر پیش ببرید:

1. ابتدا توضیحات و مثال‌ های هر مبحث را مطالعه کنید.
2. کد ها را اجرا کرده و خروجی آن‌ ها را بررسی کنید.
3. تمرین‌ ها را بدون مشاهده راه‌ حل پیشنهادی حل کنید.
4. راه‌ حل خود را با نمونه پاسخ مقایسه کنید.
5. با تغییر کد ها و آزمایش حالت‌ های مختلف ، درک خود را عمیق‌ تر کنید.
